# 🚀 Missão Espacial: Estação Orbit

Bem-vindo ao repositório de controle e monitoramento da Estação Espacial Orbit! Este projeto simula o fluxo de desenvolvimento corporativo e o protocolo de homologação em camadas para garantir a qualidade do software de suporte à vida.

## 🌍 Camadas do Ambiente (Fluxo de Branches)

Este repositório segue um protocolo de integração estruturado em três camadas distintas:

* **`develop` (Desenvolvimento):** É a base da missão onde o código é inicialmente escrito e as novas funcionalidades (como o módulo de monitoramento de suporte à vida) são implementadas.
* **`stage` (Ambiente de Testes/Homologação):** Camada intermediária para validação. O código desenvolvido em `develop` é enviado para cá para revisões e testes práticos antes do lançamento oficial.
* **`main` (Produção):** A camada final e principal do repositório. Contém apenas os módulos que passaram por todas as validações no ambiente de `stage`, garantindo um código estável e pronto para uso na estação.
